# SpamShield AI 🛡️

SpamShield AI is a lightweight, offline machine learning web application built with Python and Streamlit. It uses TF-IDF feature extraction and a Multinomial Naive Bayes classification model to detect and classify spam and phishing messages instantly.

## 🚀 Features

* **Real-time Prediction**: Instantly classifies text messages as spam or legitimate (ham).
* **Dynamic Model Training**: Trained on a robust internal dataset so no external `.pkl` model files are required to run.
* **Clean UI**: Interactive and responsive user interface built using Streamlit.
* **Privacy Focused**: Operates completely offline without sending user data to external APIs.

## 🛠️ Tech Stack

* **Language**: Python
* **Framework**: Streamlit
* **Machine Learning**: Scikit-learn (TF-IDF Vectorizer & Multinomial Naive Bayes)
* **Data Handling**: Pandas[cite: 8]
